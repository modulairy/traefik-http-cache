The square icon is used by `.traefik.yml`; the banner is used for catalog sharing and explicitly embedded in the README. Keep text alternatives when embedding artwork. Brand names and marks identify Modulairy; the project's source-code license does not grant trademark rights.

When publishing new artwork, include it in a new immutable source version so the catalog can discover it. Do not move existing version tags. Preview both GitHub and catalog rendering, as their Markdown renderers differ.
